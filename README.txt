Yasso birthday invitation website
Upload all three files from the ZIP directly to the root of your GitHub Pages repository (no folders):
- index.html
- Yasso_animated_birthday_FIXED.gif
- Yasso_second_page_animated.gif
Then enable GitHub Pages from Settings > Pages, using the main branch and /(root).
The Open Invitation button opens page 2. The Symblona bookmarks button opens the provided Instagram URL. Location deliberately has no link.
RSVP confirmation is stored only in the visitor's browser; it is not sent to the organizer. To collect RSVPs centrally, a destination such as a Google Form or backend is needed.

Music: birthday-song.mp3. Browsers may block autoplay with sound until a visitor taps the page or music button.
